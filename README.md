# ElectroStoreApp — Информационная система учёта товаров и заказов магазина электротоваров

Учебный проект по профессиональному модулю **ПМ.03 «Сопровождение и обслуживание программного обеспечения компьютерных систем»** (специальность 09.02.07 «Информационные системы и программирование», АНО ВО «СПбИЭУ»).

## Технологический стек
* **Язык и платформа:** C# 7.3, .NET Framework 4.7.2 / 4.8, WPF (Windows Presentation Foundation)
* **СУБД и доступ к данным:** PostgreSQL 17, ADO.NET (провайдер `Npgsql 4.1.x`)
* **Проектирование и документация:** pgAdmin 4 (ERD Tool, `pg_dump`), draw.io (блок-схемы по ГОСТ 19.701-90)

## Структура репозитория
* `ElectroStoreApp/` — исходный код клиентского WPF-приложения на C#
* `sql/` — SQL-скрипты создания структуры БД в 3НФ (`01_schema.sql`), наполнения данными (`02_seed_data.sql`), индексирования и проверок (`03_indexes_and_checks.sql`), ER-диаграмма (`ERD_electro_shop.pdf`)
* `import/` — очищенные CSV-файлы в кодировке UTF-8 для миграции данных (`stg_product.csv`, `stg_user.csv`, `stg_pickup.csv`, `stg_order.csv`)
* `backup/` — резервная копия базы данных (`electro_shop.sql`)
* `images/` — графические ресурсы приложения (`Logo.png`, `Logo.ico`, `picture.png`)
* `BlockSchema.drawio` / `BlockSchema.pdf` — блок-схема алгоритма работы приложения по ГОСТ 19.701-90

## Реализованный функционал
1. **База данных в 3НФ (11 таблиц):** полная ссылочная целостность (`PK`, `FK`, `UNIQUE`, `CHECK`), нормализация состава заказов и справочников, оптимизация B-Tree индексами.
2. **Авторизация и ролевая модель:**
   * **Гость** и **Авторизированный клиент** — просмотр каталога товаров с цветовой индикацией (скидка > 15% — `#2E8B57`, остаток <= 3 — `#FF8080`, нет на складе — `LightBlue`, перечёркнутая старая цена).
   * **Менеджер** — поиск по всем текстовым полям, фильтрация по поставщику и сортировка по остатку на складе в реальном времени, просмотр списка заказов.
   * **Администратор** — полный CRUD товаров (добавление, редактирование в модальном окне, масштабирование фото до `300x200` пикселей, удаление старых фото, запрет удаления товаров из заказов) и просмотр заказов.
3. **Безопасность и оптимизация:** защита от SQL-инъекций через параметризованные запросы `NpgsqlCommand`, управление ресурсами через блоки `using`, замеры производительности (`EXPLAIN ANALYZE` и `Stopwatch`).
